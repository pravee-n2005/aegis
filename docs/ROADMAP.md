# AEGIS Roadmap

1. Assistant foundation: Claude API, prompts, conversation history, FastAPI.
2. RAG: ingestion, parsing, chunking, embeddings, vector search, citations, retrieval evaluation.
3. Agent engine: tool registry, bounded loops, permissions, traces, verification.
4. Context engineering: project-scoped context, memory, relevance ranking, token budgets, isolation.
5. Advanced orchestration: LangGraph state/checkpoints and MCP integrations.
6. Deep Learning Lab: PyTorch neural-network and attention/transformer experiments.
7. Product hardening: authentication, tenancy, evaluation, observability, cost controls, deployment.

Each milestone should produce a working demo and an explanation of design decisions.
