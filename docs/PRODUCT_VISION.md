# AEGIS Product Vision

**Positioning:** A context-aware engineering workspace connecting developer knowledge, projects, and learning to practical engineering tasks.

Modes:
- Learn: explain concepts, create exercises, connect notes to projects.
- Build: inspect authorised project files, explain architecture, plan engineering work.
- Research: compare technologies and synthesize evidence from supplied sources.

Differentiation hypothesis: a learning-to-building loop — learn a concept, retain project-relevant notes, apply it to a real repository, inspect agent context/actions, then evaluate the result. This is a hypothesis to validate, not a claim of global novelty.

MVP boundary: one user, one workspace, one assistant, visible tool traces, read-only knowledge retrieval. Add RAG after the basic assistant is reliable. Add code-writing/external actions only with explicit approval and safeguards.
