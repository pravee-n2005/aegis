# AEGIS Sample Workspace Brief

AEGIS is a context-aware engineering workspace for learning, research, and building.

Initial MVP: Claude-powered conversational assistant, read-only workspace search, visible tool execution trace.

Planned knowledge capabilities: document ingestion, text extraction and chunking, embeddings, vector search, RAG, and source-grounded answers.

Product principle: start with a reliable, focused workflow and expand only after validating usefulness.
